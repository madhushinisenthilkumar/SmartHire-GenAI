# Switching to a Data Analyst Role

## Core skills needed
- SQL (joins, aggregations, window functions) — the single most requested skill in Data Analyst postings
- Excel or Google Sheets (pivot tables, VLOOKUP/XLOOKUP)
- A visualization tool: Power BI or Tableau
- Basic statistics: mean/median, distributions, correlation vs causation
- Python or R is a plus, not always required for entry-level roles

## Typical path for a career switcher
1. Learn SQL first — it appears in almost every data analyst job posting.
2. Build 2-3 portfolio projects using public datasets (Kaggle is a good source) and publish them on GitHub.
3. Learn one visualization tool deeply rather than several shallowly.
4. Target "Junior Data Analyst" or "Business Analyst" titles first if coming from a non-technical background — these often value domain knowledge (e.g. retail, finance) alongside technical skill.

## Common mistakes
- Over-investing in machine learning before mastering SQL and basic reporting — most analyst roles need reporting and dashboards, not ML.
- Portfolio projects that only show code, with no written interpretation of what the data means for a business decision.

## Interview focus areas
- SQL query writing (often live, on a shared screen)
- "Walk me through a project" — expect to explain not just what you did but why, and what business question it answered
- Basic case-style questions: "how would you measure success for X feature"
